## Условие

Дуэльный клуб собрал полный зал. Локонс распинался о своих подвигах, Снейп кривился, а Гарри и Драко уже стояли друг напротив друга с поднятыми палочками. После каждой дуэли судьи записывали, кто победил и сколько очков набрал, но к концу вечера в свитке было столько строк, что старосты сбились со счёта. Профессор Флитвик предложил не пересчитывать всё заново, а написать функцию, которая сама выберет достойных и аккуратно сложит их в итоговую таблицу.

Напишите функцию **duel\_winners(points)**, которая откроет файл базы данных **duels.db**, найдёт победителей дуэлей с достаточным числом очков и запишет их в итоговую таблицу.

На вход проверяющей системе подаётся файл базы данных SQLite 3, в котором записаны таблицы:

**Факультеты** (*Faculties*)

| Поле | Что означает |
| --- | --- |
| `id` | номер факультета |
| `faculty` | название факультета |

**Ученики** (*Students*)

| Поле | Что означает |
| --- | --- |
| `id` | номер ученика |
| `name` | имя и фамилия |
| `faculty_id` | id факультета из таблицы Faculties |
| `year` | курс, на котором учится ученик |

**Дуэли** (*Duels*)

| Поле | Что означает |
| --- | --- |
| `id` | номер дуэли |
| `winner_id` | id ученика, победившего в дуэли |
| `loser_id` | id ученика, проигравшего в дуэли |
| `points` | очки, набранные победителем |

**Итоговая таблица** (*Results*)

| Поле | Что означает |
| --- | --- |
| `no` | номер по порядку |
| `faculty` | факультет победителя |
| `student` | имя и фамилия победителя |

![scheme.png](./statement-file)

Функция **duel\_winners(points)** принимает одно число — минимальное количество очков победителя. Если же функции не передано значение этого параметра, то он принимает значение по умолчанию, равное 10. Файл **duels.db** лежит в текущем каталоге. Функция полностью заменяет содержимое таблицы **Results**: старое содержимое нужно удалить, а новое записать заново. В таблицу попадает по одной строке на каждую подходящую дуэль: номер по порядку (1, 2, 3, …), факультет и имя победителя. Строки идут в порядке возрастания идентификаторов из таблицы Duels. Если подходящих дуэлей нет, таблица Results остаётся пустой.
