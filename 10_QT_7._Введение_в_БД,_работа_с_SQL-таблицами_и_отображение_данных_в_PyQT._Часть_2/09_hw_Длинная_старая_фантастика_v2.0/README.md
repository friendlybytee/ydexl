## Условие

Напишите функцию get\_result(name), которая принимает на вход имя файла базы данных по структуре идентичной «films.db», и выполняет запрос, удаляющий все фильмы в жанре фантастики, вышедшие до 2000 года, если их длина больше полутора часов.
