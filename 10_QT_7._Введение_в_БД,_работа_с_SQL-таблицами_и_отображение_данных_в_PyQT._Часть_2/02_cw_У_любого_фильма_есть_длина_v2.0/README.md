# У любого фильма есть длина v2.0

| Характеристика | Значение |
| --- | --- |
| **Категория** | Классная работа |
| **Макс. балл** | 20 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64Mb |
| **Ввод** | input.db |
| **Вывод** | стандартный вывод или output.txt |
| **ID задачи** | `88913` |

---

## Условие

Напишите функцию **get\_result(name)**, которая принимает на вход имя файла базы данных, по структуре идентичной **films.db**, и обновляет информацию о фильмах: поле с длительностью фильма, если оно изначально пустое (пустая строка), должно стать равным 42 минутам.
