# Турнир у Волшебного фонаря

| Характеристика | Значение |
| --- | --- |
| **Категория** | Домашняя работа |
| **Макс. балл** | 25 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **Ввод** | стандартный ввод или  input.txt |
| **Вывод** | tournament.txt |
| **ID задачи** | `94976` |

---

## Условие

У Волшебного фонаря собрались герои. В турнире каждый герой должен сразиться с каждым ровно один раз. Для каждого боя случайным образом определяется победитель.

## Формат ввода

Вводится строка: герои, записанные через пробел.

## Формат вывода

Сохраните результаты всех боев в файл **tournament.txt** в формате:  
`Питер vs Тумнас: победил Питер.`

В конце подсчитайте и выведите в файл общее количество побед каждого героя (если побед не было, героя не выводите):  
`<Герой> - <количество побед>`

## Примеры

### Пример 1

**Ввод:**
```
Питер Сьюзен Эдмунд Люси
```

**Вывод:**
```
Питер vs Сьюзен: победил Сьюзен.
Питер vs Эдмунд: победил Питер.
Питер vs Люси: победил Питер.
Сьюзен vs Эдмунд: победил Эдмунд.
Сьюзен vs Люси: победил Люси.
Эдмунд vs Люси: победил Эдмунд.
Сьюзен - 1
Питер - 2
Эдмунд - 2
Люси - 1
```

## Примечания

Использование `random` обязательно.
