## Условие

Аслан собирает разведданные о войсках противника. Создайте `Excel`-файл **enemies.xlsx** с колонками:  
`Тип войск, Количество (50-500), Опасность (1-10)`.

Добавьте типы врагов из введённой строки со случайными характеристиками.  
Под данными рассчитайте общее количество врагов и озаглавьте строку *ИТОГО*. Раскрашивать ячейки не обязательно.

Вводится строка с типами врагов, записанными через запятую и пробел.  
Запишите результаты в файл **enemies.xlsx**.

### Пример вводимой строки

`Орки, Гоблины, Тролли, Варги`
