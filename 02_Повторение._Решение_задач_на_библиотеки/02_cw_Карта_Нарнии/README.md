## Условие

Люси нарисовала карту путешествий символами в текстовом файле. Потом ещё одну. И ещё.

В папке **narnia\_map** лежат текстовые файлы с названиями локаций (например, `Каменный стол.txt`, `Лампа.txt` и т. д.). Питер хочет проверить, все ли важные места отмечены.

Напишите программу, которая:

* Проверяет, есть ли файлы `txt` в папке **narnia\_map**. Если нет — выводит `"Карта ещё не создана!"`.
* Если файлы есть — выводит список всех `.txt` файлов в ней по одному в строке в алфавитном порядке и их количество в формате:  
  `Всего файлов txt: <количество>`

```
Замок Белой Колдуньи.txt
Каменный стол.txt
Лампа.txt
Парапавет.txt
Танцующий луг.txt
Всего файлов txt: 5
```
