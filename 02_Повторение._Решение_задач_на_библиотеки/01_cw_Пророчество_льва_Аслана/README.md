## Условие

Пророчество гласит, что четверых детей Адама и Евы коронуют в Нарнии. Но кого именно? В сундуке лежат имена претендентов: Питер, Сьюзен, Эдмунд, Люси, Юстэс, Джил. Аслан хочет проверить, какие комбинации возможны.

Напишите программу, которая генерирует `n` **разных** вариантов пророчества (каждый вариант — 4 уникальных имени) и выводит их на экран.

## Формат ввода

Вводится число n — количество вариантов.

## Формат вывода

Выведите варианты по одному в строке; имена в строке разделены запятой и пробелом.

Например, если введено число 5, то вывод может быть такой:

```
Питер, Сьюзен, Эдмунд, Юстэс
Джил, Питер, Сьюзен, Эдмунд
Джил, Питер, Эдмунд, Юстэс
Джил, Люси, Питер, Юстэс
Люси, Питер, Сьюзен, Юстэс
```

## Примечания

Использование `random` обязательно.
