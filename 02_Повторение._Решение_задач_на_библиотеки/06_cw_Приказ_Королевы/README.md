## Условие

В файле **decree\_template.docx** находится шаблон приказа с примерным текстом (может отличаться, но подстановки везде одинаковые):

```
Я, {{ ruler }}, повелеваю доставить {{ item }} во дворец {{ palace }}!
```

Создайте на основе шаблона указ, подставив введённые значения.

Вводится строка со значениями для подстановки, записанными через слэш.

Сохраните приказ в файл **order.docx**.

### Пример ввода

```
The White Witch/Lollipops/The Castle
```

### Результат в файле order.docx

```
Я, The White Witch, повелеваю доставить Lollipops во дворец The Castle!
```
