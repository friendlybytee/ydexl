## Условие

В дневнике Мистера Тумнаса (**tumnus\_diary.txt**) лежит запись вроде такой (именно такой файл используется в примере):  
`Встреча с Люси: 25.12.2024`

Прочитайте эту строку из файла (она может быть с любой датой, стоящей в конце строки после пробела). Определите, сколько дней осталось до этой встречи от введённой даты. Выведите сообщение:  
`До встречи осталось X дней`

В решении используйте модуль `datetime`.

### Пример ввода:

`20.12.2024`

### Ответ:

`До встречи осталось 5 дней`
