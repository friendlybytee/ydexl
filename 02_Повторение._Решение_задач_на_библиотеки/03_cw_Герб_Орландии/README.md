## Условие

Королевству Орландия нужен герб. Создайте квадратное изображение `n x n` пикселей с красным фоном. В центре нарисуйте желтый круг с красным контуром (голова льва, радиус — четверть стороны квадрата, контур — 10 пикселей), который затмевает солнце — тоже жёлтый круг с радиусом — треть стороны квадрата.

Вводится число `n` — размер стороны изображения.

Сохраните изображение в файл **emblema.png**.

#### Пример ввода

```
300
```
