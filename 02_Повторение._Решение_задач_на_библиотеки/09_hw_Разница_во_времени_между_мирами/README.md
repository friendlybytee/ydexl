# Разница во времени между мирами

| Характеристика | Значение |
| --- | --- |
| **Категория** | Домашняя работа |
| **Макс. балл** | 25 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **Ввод** | стандартный ввод или  input.txt |
| **Вывод** | worlds.txt |
| **ID задачи** | `94977` |

---

## Условие

Люси провела в Нарнии несколько дней. Напишите программу, которая получает дату входа (в формате `ДД/ММ/ГГГГ`) и дату выхода (в таком же формате) и вычисляет:

* Сколько полных дней прошло.
* Сколько часов (дни \* 24).
* Если путешествие длилось больше 7 дней — вывести `"Ты стал героем!"`, иначе `"Это было короткое приключение"`.

Все три строки записываются в файл **worlds.txt**.

В решении используйте модуль `datetime`.

## Примеры

### Пример 1

**Ввод:**
```
16/04/2027
27/04/2027
```

**Вывод:**
```
11
264
Ты стал героем!
```
