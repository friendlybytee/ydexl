## Условие

1. Разбейтесь на группы по 2-3 человека, выберите 1 человека, который создаст репозиторий (назовем его **тим-лид** — лидер команды).
2. Тим-лиду необходимо создать на **SourceCraft** репозиторий с именем **gitflow** и дать доступ к репозиторию остальным участникам группы, для этого необходимо перейти в настройки репозитория (меню "Repository settings", раздел "Roles)". И в этом разделе добавить ("New role") всех участников своей группы (2-3 человека), найдя их по логинам SourceCraft.
3. Каждому участнику группы необходимо принять приглашение в репозиторий. Приглашения отображаются на закладке рабочем столе SourceCraft.
4. Если пункты 1-3 выполнены корректно, то у всех участников группы появится доступ на запись к созданному тим-лидом репозиторию.
5. Далее всем участникам группы нужно на своем компьютере в своей домашней директории создать папку **gitflow**, перейти в неё и склонировать пустой репозиторий, созданный тим-лидом.
6. Отлично, на этом шаге у каждого участника группы должна быть директория **gitflow** с пустым локальным репозиторием и единым удаленным репозиторием. Попробуйте поработать по gitflow, для этого пусть каждый реализует в отдельных ветках 3 фичи:

   * *feature/user*YourName** (это — имя ветки), содержащую файл `YourName.txt`, в котором указан год вашего рождения;
   * *feature/list*YourName**, содержащую файл `list.txt` с вашим ФИО и
   * *feature/school*YourName**, содержащий файл `YourNameSchool.txt`, содержащий номер вашей школы.
