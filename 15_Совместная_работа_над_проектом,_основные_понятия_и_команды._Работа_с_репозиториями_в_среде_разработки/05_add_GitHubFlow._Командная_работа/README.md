## Условие

Поработайте в группе по методологии GitHubFlow.

1. Повторите этапы классных задач №2-3, только заменив имя папки на **git\_lab3\_lesson2**, а имя репозитория на **githubflow**.
2. Распределите между собой ветки так, чтобы каждый из вас попробовал «зарелизить» (то есть выпустить) как минимум 1 ветку.
3. Перейдите в веб-интерфейс **SourceCraft** на страницу репозитория, далее в меню слева надо выбрать Code->Pull requests, нажмите на кнопку «New pull request».
4. Убедитесь, что указаны верные ветки для создания пулл-реквеста:
   * *Target branch* — ветка куда сливать (**master**),
   * *Source branch* — ветка, которую надо слить — ваша ветка, которую вы хотите «выпустить в продакшн».
5. Напишите заголовок пулл-реквеста и краткое описание, нажмите «Publish pull request».
6. Пулл-реквест создан, теперь можете:
   * проверить коммиты, входящие в пулл-реквест (вкладка commits),
   * посмотреть изменения (вкладка Files Changed) или
   * принять пулл-реквест - кнопка Approve
   * влить пулл-реквест - кнопка Merge.
7. Примите пулл-реквест и повторите его для остальных веток.
8. Если у вас возникли конфликты, то их надо решить. Как это сделать, можно прочитать в официальной документации по [SourceCraft.](https://sourcecraft.dev/portal/docs/en/)
