## Условие

Последовательно выполните следующее задания:

1. Создайте в PyCharm проект git\_lesson2, откройте его
2. Склонируйте в него репозиторий <https://github.com/YandexLyceum/human.git>
3. Изучите список всех веток репозитория
4. Просмотрите содержимое файла human.txt
5. Сравните содержимое файла human.txt в ветке master с каждой из веток, которые вы видите
6. Создайте ветку boots\_buttons от ветки master, переключитесь в неё
7. Слейте в новую ветку ветки boots и buttons
8. Залейте ветку boots\_buttons (но не все остальные ветки) в свой собственный репозиторий на SourceCraft и в качестве решения этой задачи пришлите ссылку на него
