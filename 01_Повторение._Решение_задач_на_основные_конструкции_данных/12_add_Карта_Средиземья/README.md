## Условие

Карта записана в файле в виде прямоугольной матрицы чисел, которые означают количество здоровья, которое нужно затратить, чтобы пройти через эту ячейку. Фродо начинает движение с левого верхнего угла карты и может идти только вправо или вниз, за каждый шаг затрачивая указанное в ячейке количество здоровья.

Напишите функцию **travel()**, которая определит максимальное или минимальное количество здоровья, которым должен обладать Фродо, чтобы пройти всю карту до правого нижнего угла.

Функция принимает имя файла с картой и именованный аргумент *key* со значением по умолчанию *max* (функция *max*) — найти максимальное здоровье (если значение *min*, то нужно найти минимальное здоровье).

Функция возвращает найденное число.

## Примеры

### Пример 1

**Ввод:**
```
# Содержимое файла map.txt
1 2 3
4 5 6
7 8 9

# Вызов функции
print(travel('map.txt', key=max))
```

**Вывод:**
```
29
```
