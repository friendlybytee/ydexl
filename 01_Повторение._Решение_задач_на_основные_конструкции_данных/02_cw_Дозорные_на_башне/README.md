# Дозорные на башне

| Характеристика | Значение |
| --- | --- |
| **Категория** | Классная работа |
| **Макс. балл** | 14 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **ID задачи** | `94997` |

---

## Условие

Стражи на башне Минас Тирита сменяют друг друга. Изначально на башне `N` стражников. В первую минуту на башню поднимается ещё 1 стражник. Каждую следующую минуту — на 2 стражника больше, чем в предыдущую. Дозорных должно стать не меньше `M`.

Напишите программу, которая определит время, через которое на башне будет нужное количество стражников, и сколько стражников окажутся на башне в этот момент.

## Формат ввода

Вводятся два числа: начальное количество стражников и требуемое их число.

## Формат вывода

Выведите две строки:  
`Время - <сколько прошло минут>.`  
`Количество дозорных - <количество стражников на башне>.`

## Примеры

### Пример 1

**Ввод:**
```
13 121
```

**Вывод:**
```
Время - 11.
Количество дозорных - 134.
```
