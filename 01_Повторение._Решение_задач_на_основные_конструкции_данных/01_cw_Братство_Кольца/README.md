# Братство Кольца

| Характеристика | Значение |
| --- | --- |
| **Категория** | Классная работа |
| **Макс. балл** | 14 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **ID задачи** | `94996` |

---

## Условие

Хоббиту разрешают присоединиться к Братству Кольца, если его рост не ниже 90 см (средний рост хоббита) и не выше 140 см.

Напишите программу, которая пропустит хоббита в Братство, если его рост подходит, и не пропустит, если слишком мал или слишком высок.

## Формат ввода

Вводится строка чисел, записанных через пробел — рост хоббитов.

## Формат вывода

Для каждого роста программа выводит `"Можешь идти"`, если он подходит, и `"Оставайся в Шире"` в противном случае. Каждый результат выводится с новой строки.

## Примеры

### Пример 1

**Ввод:**
```
85 94 145 133 70
```

**Вывод:**
```
Оставайся в Шире
Можешь идти
Оставайся в Шире
Можешь идти
Оставайся в Шире
```
