## Условие

В арсенале Арагорна могут остаться только вещи с длиной, не больше средней из всех имеющихся.

Напишите функцию, которая выберет только подходящие вещи.

Функция **arsenal()** принимает произвольное количество аргументов-строк.

Возвращает функция список отобранных вещей в алфавитном порядке и без повторений, записав каждую из них с прописной буквы, а остальные — строчными.

## Примеры

### Пример 1

**Ввод:**
```
weapon = ['sword', 'longsword', 'dagger',
          'battleaxe', 'bow', 'longbow', 'arrows']
print(*arsenal(*weapon), sep='\n')
```

**Вывод:**
```
Arrows
Bow
Dagger
Sword
```
