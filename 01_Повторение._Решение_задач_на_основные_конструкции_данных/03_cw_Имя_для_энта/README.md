# Имя для энта

| Характеристика | Значение |
| --- | --- |
| **Категория** | Классная работа |
| **Макс. балл** | 14 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **ID задачи** | `94998` |

---

## Условие

Энты — древние пастыри деревьев. Чтобы считаться красивым, имя должно соответствовать трём правилам:

* длина имени должна быть не меньше 4 и меньше 20 символов;
* начинаться имя должно на гласную и заканчиваться на согласную букву;
* имя не должно содержать две гласные подряд.

Для каждого из введённых имён выведите результат проверки:

* если имя красивое, выведите: `Красиво!`
* если не подходит длина, то `Слишком короткое.` или `Слишком длинное.`
* если неверное начало или конец, то `Неверное начало.` или `Неверный конец.`
* если не подходит последнее условие, то: `Две гласные <первое сочетание гласных в нижнем регистре> подряд.`

## Формат ввода

Вводятся строки имён, пока не будет введена пустая строка.

## Формат вывода

Для каждого имени выведите вердикт, каждый из которых проверяется в описанном порядке.

## Примеры

### Пример 1

**Ввод:**
```
Elrond
Isildur
Eol
Amandile
Aearon
```

**Вывод:**
```
Красиво!
Красиво!
Слишком короткое.
Неверный конец.
Две гласные ae подряд.
```
