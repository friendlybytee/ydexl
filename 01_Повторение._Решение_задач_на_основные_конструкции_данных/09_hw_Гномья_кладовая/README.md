# Гномья кладовая

| Характеристика | Значение |
| --- | --- |
| **Категория** | Домашняя работа |
| **Макс. балл** | 25 |
| **Ограничение времени** | 1 секунда |
| **Ограничение памяти** | 64 Мб |
| **ID задачи** | `95004` |

---

## Условие

В кладовой у гномов в ряд стоят бочонки с медом. Тёмный мёд хранится в бочонках нечётного размера, светлый — чётного.

Напишите программу, которая подсчитает количество тёмного и светлого мёда в кладовой.

## Формат ввода

Вводится строка чисел через произвольное количество пробельных символов — заполнение каждого бочонка.

## Формат вывода

Выведите две строки:  
`Тёмного мёда: <общее количество>.`  
`Светлого мёда: <общее количество>.`

## Примеры

### Пример 1

**Ввод:**
```
2 7   13  5  1
```

**Вывод:**
```
Тёмного мёда: 26.
Светлого мёда: 2.
```
