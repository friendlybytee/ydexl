## Условие

Создайте новый публичный репозиторий с произвольным именем, в котором разместите следующие файлы:

1. Файл main.py, который будет выводить форму с использованием компонентов PyQT с расположенной на ней кнопкой. После нажатия кнопки на форме должны появляться окружности желтого цвета и случайного диаметра. Интерфейс программы загружается из файла UI.ui
2. Файл UI.ui, который содержит интерфейс программы

Ссылку на репозиторий и первые 7 символов хэша коммита пришлите в качестве решения.
