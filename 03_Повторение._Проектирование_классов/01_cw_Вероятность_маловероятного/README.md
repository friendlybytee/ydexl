## Условие

Говорят, во Вселенной возможно всё, что не запрещено физическими законами, нужно просто подольше подождать. Пока ждём, напишем класс для работы с вероятностью.

Создайте класс **ImprobabilityDrive**. При создании принимает `probability` (число от 0 до 1). Добавьте методы:

* `get_probability()` — возвращает текущую вероятность.
* `set_probability(value)` — устанавливает новую вероятность, проверяя что `0 <= value <= 1`. Если значение вне диапазона — кидать `ValueError` с сообщением: `"Вероятность может быть только в диапазоне [0, 1]"`.
* `jump()` — если `probability < 0.5`, возвращает строку `"Прыжок через гиперпространство совершён!"`, иначе возвращает строку `"Ничего не произошло, всё слишком предсказуемо"`.

## Примеры

### Пример 1

**Ввод:**
```
impd = ImprobabilityDrive(0.49)
print(impd.get_probability())
print(impd.jump())
```

**Вывод:**
```
0.49
Прыжок через гиперпространство совершён!
```
