## Условие

В ресторане у вогонов подают знаменитый коктейль `"Пангалактический грызлодёр"`. Вогоны — существа привередливые, они следят за качеством напитков и не подадут то, что может навредить посетителю.

Создайте несколько собственных исключений, унаследовав их от базового класса `Exception`:

* `DangerousDrinkError` — для слишком опасных напитков.
* `HighSugarError` — для напитков с высоким содержанием сахара.
* `TooFizzyError` — для слишком шипучих напитков.

Напишите функцию **order(drink\_name, sugar\_amount)**, которая:

* Принимает название напитка (`drink_name`) и количество сахара в граммах (`sugar_amount`).
* Вычисляет шипучесть напитка по формуле:  
  `шипучесть = количество_слов_в_названии × (sugar_amount % 3)`  
  (Количество слов определяется по пробелам в названии.)
* Проверяет три условия:

1. Если в названии напитка содержится подстрока `"грызлодёр"` или `"gargle blaster"` (без учёта регистра) — возбудить исключение `DangerousDrinkError` с сообщением:  
   `"Вогоны отказались подавать грызлодёр: слишком опасно для землян!"`
2. Если количество сахара (`sugar_amount`) превышает 50 граммов — возбудить исключение `HighSugarError` с сообщением:  
   `"Слишком много сахара! {sugar_amount} г превышает допустимую норму в 50 г."`
3. Если вычисленная шипучесть больше 10 — возбудить исключение `TooFizzyError` с сообщением:  
   `"Напиток слишком шипучий! Шипучесть = {fizziness}"`

Если ни одно из условий не нарушено, функция должна вернуть строку:  
`"Заказ принят! Приятного аппетита!"`  
Условия проверяются именно в описанном порядке.

## Примеры

### Пример 1

**Ввод:**
```
try:
    print(order("Чай", 10))
except Exception as e:
    print(type(e).__name__, e)
```

**Вывод:**
```
Заказ принят! Приятного аппетита!
```
