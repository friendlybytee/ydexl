## Условие

В романе "Автостопом по Галактике" у персонажей есть разнообразное энергетическое оружие. Давайте создадим иерархию классов для моделирования такого оружия.

Создайте абстрактный класс **Weapon**, используя модуль **abc**:

* Класс **Weapon** должен наследоваться от **ABC**.
* Добавьте атрибут `ammo` (боезапас), который передаётся в конструктор (**init**) и сохраняется в экземпляре.
* Добавьте абстрактный метод `fire()`, который должен быть переопределён в дочерних классах.

Создайте собственное исключение **OutOfAmmoError**, унаследованное от **Exception**.

Создайте класс **Laser**, наследующий от **Weapon**:

* В конструкторе принимает начальное количество патронов (боезапас) и передаёт его родительскому классу.
* Метод `fire()`:  
  Если патронов больше 0: тратит 1 патрон и выводит на экран строку  
  `"Пиу-пиу! Осталось выстрелов: {ammo}"` (где `ammo` — оставшееся количество патронов после выстрела).  
  Если патронов нет (0): выводит строку `"Батарея разряжена"` (исключение не возбуждается).

Создайте класс **Blaster**, наследующий от **Weapon**:

* В конструкторе принимает начальное количество патронов (боезапас) и передаёт его родительскому классу.
* Метод `fire()`:  
  Если патронов 3 или больше: тратит 3 патрона за один выстрел и выводит на экран строку  
  `"Бдыщ-бдыщ! Осталось выстрелов: {ammo}"` (где `ammo` — оставшееся количество патронов после выстрела).  
  Если патронов меньше 3 (то есть 0, 1 или 2): возбуждает исключение **OutOfAmmoError** с сообщением:  
  `"Недостаточно зарядов для выстрела из бластера. Нужно 3, осталось {ammo}"`

## Примеры

### Пример 1

**Ввод:**
```
laser = Laser(5)
laser.fire()
laser.fire()
laser.fire()
laser.fire()
laser.fire()
laser.fire()
laser.fire()
blaster = Blaster(10)
blaster.fire()
blaster.fire()
blaster.fire()

blaster2 = Blaster(2)
try:
    blaster2.fire()
except OutOfAmmoError as e:
    print(e)
```
