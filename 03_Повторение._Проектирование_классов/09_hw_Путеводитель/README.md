## Условие

Создайте иерархию исключений для путеводителя "Автостопом по Галактике", вдохновляясь романом Дугласа Адамса.

* **GalaxyGuideError** — базовый класс для всех ошибок путеводителя (наследуется от **Exception**).
* **PageNotFoundError** — страница не найдена (наследуется от **GalaxyGuideError**).
* **BabbleFishError** — проблемы с универсальным переводчиком (наследуется от **GalaxyGuideError**).
* **InvalidCoordinatesError** — неверные координаты планеты (наследуется от **GalaxyGuideError**).

Напишите функцию **search\_planet**(*guide, planet\_name, coordinates*).  
Параметры:

* `guide` — словарь, где ключ — название планеты (строка), значение — кортеж: (описание, координаты).
* `planet_name` — название планеты, которую нужно найти (строка).
* `coordinates` — кортеж из двух чисел `(x, y)` — заданные координаты.

Логика работы:

* Если планета не найдена в словаре `guide` — возбудить исключение `PageNotFoundError` с сообщением:  
  `"Страница о планете '{planet_name}' не найдена в путеводителе."`
* Если планета найдена, но переданные координаты не совпадают с координатами планеты из словаря — возбудить исключение `InvalidCoordinatesError` с сообщением:  
  `"Неверные координаты для планеты '{planet_name}'. Ожидалось {correct_coords}, получено {coordinates}"`
* Если планета найдена и координаты совпадают:  
  Попытаться получить описание планеты.  
  Если описание пустое или равно `None` — возбудить исключение `BabbleFishError` с сообщением:  
  `"Не удалось перевести описание планеты '{planet_name}': язык не распознан."`  
  Если описание есть — вернуть строку:  
  `"Описание планеты {planet_name}: {description}"`

## Примеры

### Пример 1

**Ввод:**
```
guide = {
    "Магратея": ("Удивительная планета, где горы парят в воздухе.", (10, 20)),
    "Бетельгейзе": ("", (5, 15)),  # пустое описание
    "Арктур": (None, (0, 0))  # описание отсутствует
}

print(search_planet(guide, "Магратея", (10, 20)))
try:
    search_planet(guide, "Вогспир", (0, 0))  # PageNotFoundError
except Exception as e:
    print(e)
try:
    search_planet(guide, "Магратея", (99, 99))  # InvalidCoordinatesError
except Exception as e:
    print(e)
try:
    search_planet(guide, "Бетельгейзе", (5, 15))  # BabbleFishError
except Exception as e:
    print(e)
try:
    search_planet(guide, "Арктур", (0, 0))  # BabbleFishError
except Exception as e:
    print(e)
```

**Вывод:**
```
Описание планеты Магратея: Удивительная планета, где горы парят в воздухе.
Страница о планете 'Вогспир' не найдена в путеводителе.
Неверные координаты для планеты 'Магратея'. Ожидалось (10, 20), получено (99, 99)
Не удалось перевести описание планеты 'Бетельгейзе': язык не распознан.
Не удалось перевести описание планеты 'Арктур': язык не распознан.
```
