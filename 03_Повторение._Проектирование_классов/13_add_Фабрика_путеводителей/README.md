## Условие

Функция `make_dataclass` из модуля `dataclasses` позволяет создавать датаклассы на лету, без написания класса с помощью ключевого слова `class`. Используйте её, чтобы динамически создать класс для записей путеводителя по галактике.

Используйте `make_dataclass` для создания класса **GuideEntry** со следующими полями:

* `planet` — тип `str` (обязательное поле).
* `entry` — тип `str` (обязательное поле).
* `danger_level` — тип `int`, значение по умолчанию 0.

Создайте экземпляр этого класса для планеты `"Магратея"` с описанием `"Планета, созданная специально для строительства..."` и уровнем опасности 10.

## Примеры

### Пример 1

**Ввод:**
```
from dataclasses import is_dataclass

print(is_dataclass(GuideEntry))
print(magrathea)
```

**Вывод:**
```
True
GuideEntry(planet='Магратея', entry='Планета, созданная специально для строительства...', danger_level=10)
```
